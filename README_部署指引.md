# 云端每日自动采集 · 部署指引（3 分钟，零技术门槛）

部署后：**每天北京时间早上自动云端采集价格，电脑不开机数据也不断更。** 本机每天会自动从云端同步数据；云端没采的日子本机自己采（双保险互斥，绝不重复采集）。

## 第一步：上传文件到仓库（2 分钟）

1. 浏览器打开您的仓库：https://github.com/juandabbissa-prog/ZXT
2. 点 **Add file → Upload files**
3. 把本压缩包解压后的 **crawler 文件夹** 和 **.github 文件夹** 一起拖进网页（注意：.github 是隐藏文件夹，Windows 资源管理器里如果看不到，请在文件夹选项勾选「显示隐藏文件」；也可以分两次拖：先拖 crawler，再单独拖 .github）
4. 页面底部点 **Commit changes** 绿色按钮

## 第二步：手动验证跑一次（立即验证）

1. 仓库页面上方点 **Actions** 标签
2. 左侧点 **daily-snapshot** → 右侧 **Run workflow** 下拉 → 点绿色 **Run workflow** 按钮
3. 等约 60-90 分钟（351 间全量），刷新页面看到绿色对勾 ✅ = 成功
4. 成功后仓库会多出一个 **data 分支**，里面是最新数据库，本机下次同步自动取用

## 第三步：完事

之后每天北京时间 05:47 云端自动跑，无需任何操作。

- 想看某天跑得怎么样：Actions 标签页里有每次运行记录（绿勾=成功，红叉=失败，点进去可看日志）
- 失败时运行日志会自动存为附件（Artifacts），下载发给开发即可定位
- 免费额度说明：每天约 60-90 分钟，每月约 2000-2700 分钟，GitHub 免费额度 2000 分钟/月——如月底额度不足，该月最后几天由本机调度兜底，数据依然不断更

## 注意事项

- 云端从 GitHub 海外服务器访问目标站，首次手动验证跑完请告知开发核对数据入库是否正常
- 本压缩包内不含任何密钥（采集无需密钥；GITHUB_TOKEN 由平台自动注入）
- 采集频率、间隔、标识等合规参数与本机版完全一致，未做任何改动
